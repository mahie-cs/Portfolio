About

No server of its own.

Lucid runs on your phone and talks directly to YouTube.

01

Straight to YouTube

Lucid speaks YouTube’s internal API and plays through Media3 ExoPlayer with an on-disk cache.

02

Solved on-device

The signature cipher and the n parameter are solved on your phone and never sent to a third-party server.

03

Yours to keep

Your library, downloads and lyrics cache live in a Room database on your phone.

Questions

Is Lucid free?

Yes. Lucid is free software under the GNU GPL v3.0, and the full source is on GitHub.

Which APK should I download?

For almost any modern phone, arm64-v8a. Older 32-bit phones need armeabi-v7a. The universal file works everywhere but is about twice the size. x86_64 is for emulators and Chromebooks. If the installer says the app is not compatible, try the universal file.

Where do I download it?

The Download buttons on this site open a short list of builds. Choosing one starts a direct download from the official GitHub release. Only install Lucid from there.

Do I need an account?

Sign in with Google to sync your YouTube Music library, likes and follows. You can switch accounts inside the app.

Is a desktop version planned?

Yes, it is upcoming. There is no release date yet, so watch the GitHub repository for news.

Are there features that rely on a server?

Listen Together and Play Anywhere need a relay server. By default they use a relay run by the Limusic project, not by Lucid, and Play Anywhere expects the Limusic desktop app on the other end.

Where does Lucid come from?

Lucid is a fork of Limusic for Android by SimoHypers, which is built on SimpMusic by maxrave-dev.
